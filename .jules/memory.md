- In HTML forms, always pair programmatic `required` attributes on inputs with a visible indicator (e.g., an asterisk wrapped in `<span aria-hidden="true">`) on the corresponding `<label>`. However, do not repurpose validation classes or error-state colors (e.g., `#ff8a80` or `#dc3545`) for these indicators, as it breaks semantic meaning and conveys a false state of error to sighted users. Retain existing specific styling (like `color: var(--c-need-bar, #c4813a)`) designed for the indicator.
- ESP-IDF caches the generated `sdkconfig` file. Modifying `sdkconfig.defaults` or custom config profiles will not propagate to `build/config/sdkconfig.h` if an active `sdkconfig` already exists in the project root. To apply changes, delete the active `sdkconfig` and run `idf.py reconfigure`, or modify the active `sdkconfig` directly.
- The ESP32 project integrates with the playnet.earth API using JSON-RPC over `POST /api/mcp`. It relies on the device's existing Reticulum Ed25519 identity (`libsodium`) to generate RFC 9421 HTTP Message Signatures for authentication. Strict RFC 9421 compliance requires derived components like `@method` to be lowercase (e.g., 'post') in the signature base string.
- The project must remain anchored on ESP-IDF v5.4.1. Do not downgrade to older versions (e.g., v5.1.x), as it causes cascading toolchain regressions and breaks components relying on the modern driver model like `led_strip` and the USB host stack.
- The architecture incorporates a Community Bulletin Board backed by a local SQLite database for guestbook interactions, and an in-browser audio player API (`audio_api.c`, `audio.html`) for media streaming.
- The Reticulum Link Protocol implementation restricts active links to one per interface (e.g., 1 LoRa link, 1 Wi-Fi link) to prevent RF collisions on half-duplex PHYs while allowing independent concurrent transfers. Incoming LinkRequests on an already busy interface must be rejected, and an idle timeout must reset inactive links.
- To satisfy RadioLib timing accuracy requirements on ESP32, either ensure `CONFIG_FREERTOS_HZ=1000` is successfully applied in the active `sdkconfig`, or bypass the check by setting the C compiler macro `RADIOLIB_RELAX_RTOS_TICK=1` via `add_compile_definitions(RADIOLIB_RELAX_RTOS_TICK=1)` in the top-level `CMakeLists.txt`. Do not define it as a Kconfig symbol.

- The `espressif/usb_host_msc` component is strictly required for the e-book reader's local storage mounting functionality and must not be removed or disabled.
- The SX1262 LoRa hardware (Waveshare Core1262) has a strict FIFO buffer MTU limit of 255 bytes, which must be accounted for when transmitting large frames like Reticulum/LXMF payloads.
- When applying CSS focus highlights to form inputs and interactive elements, prefer the `:focus-visible` pseudo-class over `:focus`. This preserves accessibility for keyboard navigation without causing unwanted focus rings for mouse users.
- When implementing dynamic status messages, loading states, or progress text (like upload progress) in HTML interfaces, applying `aria-live` directly to an element that toggles its `display` property can cause screen readers to fail. Instead, always wrap the text nodes in a permanent `aria-live="polite"` or `aria-live="assertive"` container upon initial render so screen readers are correctly notified of state changes.
